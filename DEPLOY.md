# LiftShift Mini — инструкция по запуску в Telegram

Приложение полностью готово. Код ключей не требует — нужно только
создать бота и выложить собранное приложение на HTTPS-хостинг.

## Что понадобится от тебя

1. **Telegram-аккаунт** — больше ничего.
2. **Аккаунт Cloudflare** (бесплатный) — для хостинга на Cloudflare Pages.
3. **Токен бота** — получишь у @BotFather на шаге 2 (просто сохрани его,
   в код вставлять ничего не надо).

---

## Шаг 1. Собрать приложение

```bash
npm install
npm run build
```

Готовый сайт появится в папке `dist/`.

## Шаг 2. Создать бота в @BotFather

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. `/newbot` → придумай имя (например, `LiftShift Mini`) и username
   (например, `liftshift_mini_bot`).
3. BotFather выдаст **токен** вида `123456789:AA...` — сохрани его.
   Для MVP он не используется в коде (авторизация через Telegram
   происходит автоматически), но понадобится, если позже добавишь
   бэкенд с синхронизацией.

## Шаг 3. Выложить на Cloudflare Pages

Вариант А — через сайт (проще всего):

1. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com) →
   **Workers & Pages** → **Create** → **Pages** → **Upload assets**.
2. Назови проект (например, `liftshift-mini`) — получишь домен
   вида `liftshift-mini.pages.dev`.
3. Загрузи содержимое папки `dist/` (drag-and-drop).
4. Деплой займёт ~30 секунд. URL вида `https://liftshift-mini.pages.dev`.

Вариант Б — через CLI (если установлен Node):

```bash
npx wrangler pages deploy dist --project-name=liftshift-mini
```

(при первом запуске wrangler попросит войти в аккаунт Cloudflare —
откроется браузер, никакие ключи вручную вводить не нужно).

## Шаг 4. Привязать Mini App к боту

1. В @BotFather: `/myapps` (или `/newapp`, если список пуст) → выбери бота.
2. Укажи:
   - **Title**: LiftShift Mini
   - **Short name**: liftshift
   - **URL**: `https://твой-проект.pages.dev` (из шага 3)
   - **Photo**: любая иконка 640×360
3. Отправь `/setmenubutton` → выбери бота → укажи тот же URL и текст
   кнопки, например «Открыть трекер».
4. Готово: открой чат с ботом и нажми кнопку меню — приложение
   запустится внутри Telegram.

## Шаг 5 (опционально). Свой домен

Pages → твой проект → **Custom domains** → привяжи свой домен.
Telegram требует только HTTPS — `*.pages.dev` его уже даёт.

## Что уже работает без бэкенда

- Все 4 вкладки, справочник упражнений, свои упражнения
- PR-детект, статусы, рекомендации, тепловая карта мышц
- Тема Telegram (светлая/тёмная), haptics, MainButton/BackButton
- Данные хранятся локально на устройстве пользователя (localStorage)

## Если позже захочешь синхронизацию между устройствами

Слой хранения вынесен в `src/lib/storage.ts` — там единая точка
чтения/записи. Для бэкенда понадобятся:

- токен бота (шаг 2) — для проверки `initData` на сервере;
- бесплатный Workers + D1/KV на том же Cloudflare-аккаунте;
- Telegram ID пользователя уже приходит в `initDataUnsafe.user.id`.
